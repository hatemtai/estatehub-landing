Questions before you buy

The practical details of running and customising EstateHub.

What do I need to run it?

Node.js 20.9 or newer, pnpm, and the URL of an EstateHub REST API. Copy the example environment file, set the API URL, then run the install and dev commands. The API URL is the only required variable.

Where can I deploy it?

Anywhere Next.js runs. Import the repository into Vercel or a similar platform, or build it and serve it from your own Node server behind a reverse proxy such as Nginx or Caddy.

Can I rebrand it without editing code?

Yes. The platform name, logo, favicon and brand colours are set in the admin console and load from the API, so a rebrand needs no rebuild. For deeper changes, the design tokens live in one stylesheet.

Do the maps need a paid API key?

No. The listing map uses Leaflet with OpenStreetMap tiles, which need no key.

Is dark mode available everywhere?

The seller portal and admin console switch between light and dark. The public site and customer account are light, and the design system documentation lists the steps to opt them in.

How are social sign-in, storage and email configured?

From the admin console under Settings, Integrations. Credentials are not environment variables, and saved secrets are write-only: the console shows whether a value is set, never the value itself.

Which AI providers does AI search support?

OpenAI, Anthropic and Gemini. An administrator picks the provider and model and switches the feature on. When it is off, the ordinary search and filters work as usual.
