Questions before you buy

Short answers to the common ones.

Which license do I need?

If people pay to use your platform, through commission, listing fees or a subscription, choose the Extended License. If it is free for its users, the Regular License is enough. Each license covers one website.

Is the back end included?

Yes. You get the Next.js front end and the Django API, with the full source of both. No extra purchase and no hosted service.

What do I need to run it?

Node.js 20.9+ and pnpm for the front end. Python 3.12, PostgreSQL and Redis for the API. Copy the example environment files, run the migrations, and connect the two.

Where can I host it?

The front end runs anywhere Next.js does, such as Vercel. The API runs on any VPS with Python, PostgreSQL and Redis, and a Dockerfile is included.

How do buyers pay?

By bank transfer. The buyer uploads a receipt and your team verifies it. There is no card gateway built in, but we can add one as part of a customisation.

Can I rebrand it without touching code?

Yes. The name, logo, favicon and brand colours are settings in the admin console.
